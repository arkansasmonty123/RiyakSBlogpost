# THE INVESTIGATION — Frontend

React 19 + Vite frontend (`frontend/`).

## Overview
- Routes/session: `frontend/src/App.tsx`
- API client: `frontend/src/api.ts` (backend contracts)
- Pages: `frontend/src/pages/`
- Components: `frontend/src/components/`, `frontend/src/features/`, `frontend/src/ui/`, `frontend/src/hooks/`

## Commands
```bash
cd frontend
npm run dev        # Vite dev server (HMR)
npm run build      # tsc -b && vite build
npm run lint       # oxlint
npm run preview    # preview built output
```
