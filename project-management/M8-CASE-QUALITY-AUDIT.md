## Method & honesty note

Each of the 14 M8-4 dimensions is scored 0–3 (max total **42**). Every dimension declares a method:

- **automated** — objective structural facts read from the DB.
- **heuristic** — deterministic threshold proxy; directionally useful, confirm with a human.
- **human_review** — cannot be reliably automated; the number is a PLACEHOLDER proxy and must be confirmed by a human reviewer.

Ratings: **Publication-ready** ≥34 · **Needs refinement** ≥25 · **Draft / substantial work** <25.
Low scores are warnings only — this script never fails on quality.

| # | Dimension | Method | Max rubric (abridged) |
|---|---|---|---|
| 1 | Premise quality | heuristic | 3 = distinct, specific description + non-templated briefing + >=3 objectives & >=2 initial facts; 2 = most of those; 1 = generic/templated; 0 = missing core text. |
| 2 | Narrative coherence | human_review | Proxy only: 3 = authored narrative timeline, hidden events, and a distinct briefing; lower when templated. A human must read the prose to confirm. |
| 3 | Canonical truth integrity | automated | 3 = culprit is an authored suspect, all solution fields present, timelines/clues valid; 1 point deducted per missing structural pillar. |
| 4 | Suspect motivations | heuristic | 3 = distinct motive per suspect (+alibi); 2 = mostly distinct; 1 = reused/generic motives; 0 = missing. |
| 5 | Evidence quality | automated | 3 = >=8 evidence, >=4 categories, timeline refs + several trigger types; scaled down for thinner sets. |
| 6 | Deduction difficulty / fair challenge | heuristic | 3 = gated evidence, multiple trigger types, and NO culprit name leaked into player-facing text; leak costs 1 point. |
| 7 | Alternative hypotheses / red herrings | automated | 3 = >=2 red herrings and >=2 alternative theories with hidden events; 1 = only a token of each. |
| 8 | Evidence-to-conclusion traceability | automated | 3 = clue resolutions cover evidence, timeline events cite evidence, evidence carries hypothesis links. |
| 9 | Specialist relevance | automated | 3 = >=3 assigned specialists with case-specific relevance and a knowledge pack; scaled down when absent. |
| 10 | Knowledge opportunities | automated | 3 = knowledge pack + >=3 artifacts + learning objectives + >=1 disagreement; scaled down when absent. |
| 11 | Perspective relevance | human_review | Proxy only: reasoning-rich content (competing theories, red herrings) invites perspective lenses; confirm applicability by human. |
| 12 | Discovery clue relevance | automated | 3 = an authored discovery-clue package with >=3 clues; 1 = none / empty. |
| 13 | Ending quality | heuristic | 3 = substantial solution explanation + authored actual timeline + no spoiler leak into objectives/briefing. |
| 14 | Replayability | heuristic | 3 = multiple alternative theories, multiple red herrings, multiple gated evidence paths. |

## Gaps in automated scoring / human review needed

- **Narrative coherence** and **perspective relevance** are marked `human_review`; their scores are proxies only and must be confirmed by reading the prose and mapping reasoning lenses.
- Intent-based dimensions (premise originality, motive plausibility, fair difficulty, ending satisfaction, replay value) cannot be fully judged from structural counts.
- The culprit-name-in-player-text check is a keyword heuristic (full name in objectives/briefing); it can miss indirect spoilers and should be human-confirmed.
- No spoilers are emitted: canonical solution details are deliberately excluded from all outputs.
